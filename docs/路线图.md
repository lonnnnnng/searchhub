## v1.3（规划）

**阶段目标**：增强可用性与体验。

- [ ] 结果分页 / "加载更多"完善（多站统一翻页）
- [ ] 海报缩略图展示（多站已有 poster 字段）
- [ ] 收藏 / 历史搜索记录
- [ ] 排序（按站 / 按年份 / 按清晰度）
- [ ] 深色 / 浅色主题跟随系统（当前跟随）

> 注：v1.1 规划中的"站点手动拖动排序"已**取消**——流式输出下 tab 按返回顺序动态追加，排序意义不大且会造成歧义。

## v1.4（规划）

**阶段目标**：提升"找资源"效率。

- [ ] 磁力解析种子内文件列表（BT影视等已含磁力）
- [ ] 相似资源合并（同一片名高清重封 / 多盘位合并展示）
- [ ] 复制提取码快捷操作（网盘场景）
- [ ] 查看资源源站（浏览器打开原详情页）
- [ ] 分享 / 导出资源清单
- [ ] 关键词联想 / 最近热搜

## v2.0（远期探索）

- [ ] Web 端 / 桌面端（复用适配器逻辑）

## 维护约定

- **站点失效响应**：站点改版后优先修适配器，其次考虑换域名（设置页可改，无需发版）。
- **新增站点节奏**：每次新增附 jsoup 本地预验证 + 真机抽查，更新「站点对接文档」。
- **验证码**：雪落验证码已恢复，作为每次发版回归项（弹窗→提交→结果全链路真机过一遍）。
- **体积**：保持 R8 裁剪，新增依赖前评估体积影响，杜绝死依赖。
- **文档纪律**：功能变更同步更新 README / 技术文档 / 需求文档。
