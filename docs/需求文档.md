# SearchHub 需求文档

> 本文档记录产品背景、目标用户、功能需求与非功能需求。

## 1. 背景与目标

### 1.1 背景

用户平时从多个影视 / 网盘资源站点找资源（电影、剧集、短剧、动漫），每个站都要：
- 单独打开、单独输入关键词搜索
- 不同站搜索方式 / 资源格式各异（磁力、网盘、种子、迅雷）

重复操作成本高，且站点域名经常变更、部分站点有验证码 / 防护门槛。

### 1.2 目标

Build 一个 Android 应用，**输入一次关键词，聚合所有接入站点的搜索结果**，按站源分组展示，进入详情即可一键取得可下载资源（磁力 / 网盘链接 / 种子）。

### 1.3 目标用户

- 常看影视剧集、需要网盘 / BT 下载资源的个人用户
- 对多个资源站有依赖、反感重复搜索的"找资源重度用户"

## 2. 需求范围

### 2.1 范围界定

- **In scope**：多站搜索聚合、按站 tab、详情资源（磁力/网盘/种子）、域名可配置、验证码手动处理、代理可选
- **Out of scope**：
  - 不做在线播放（仅资源索引）
  - 不做账号 / 会员体系
  - 不做资源上传 / 存储（纯聚合索引）
  - 不做自动打码（验证码采用手动弹图，由用户确认）

## 3. 功能需求（FR）

### FR-1 多站聚合搜索

- 输入关键词（支持中英文），一次请求并发搜索所有「启用」站点
- 搜索结果去重（按 detailUrl）
- 单站失败 / 超时不影响其它站
- 全部灵感：S 级需求，默认必须有

**验收**：搜索 "batman"，聚合结果跨多个站（实测 13 站 192 条）。

### FR-2 按站源分 Tab

- 结果按 sourceSite 分组，自动生成 `全部(N)` + 每站 `站点名(N)` tab
- Tab 超屏可**横向滚动**（ScrollableTabRow）
- 单站 tab 内隐藏卡片上的来源站标签（已在该站 tab 中）
- 空结果站点不生成 tab

### FR-3 详情页资源

- 展示标题、元信息、简介（如有）
- 资源列表按类型标注：磁力 / 网盘 / 种子 / 迅雷 / 电驴 / 直链
- 网盘含提取码展示
- 二次跳转类资源提供「解析链接」按钮（如 BT影视 tdown、云集 POST、SeedHub base64）
- 「复制链接」写入剪贴板；「打开」跳系统浏览器

### FR-4 站点配置

- 设置页列出所有站点：名称 / ID / 域名 / 搜索模板 / 启停开关
- **域名可修改**：站点换域名后改 baseUrl 即用
- 停用站点不参与搜索
- 新站点随版本自动加入（配置增量合并）

### FR-5 网络代理

- 可选 HTTP 代理（host/port）
- 适配 Clash 场景（默认提示 127.0.0.1:7890）

### FR-6 验证码（雪落影视）

- 搜索触发验证码时弹出 Dialog：验证码算术题图片 + 输入框
- 图片放大显示（等比 2 倍，不形变、不铺满）
- 「刷新」按钮换图、「取消」放弃该站、「提交」校验
- 答对后同 cookie 会话免验证约 30 分钟
- 答错自动换新图重弹（最多 3 次）

## 4. 非功能需求（NFR）

### NFR-1 兼容性
- minSdk 26（Android 8.0+），targetSdk 36

### NFR-2 性能
- 多站并发搜索，单站超时 20s 兜底
- 结果懒加载 / 分页（部分站单页，部分支持分页）

### NFR-3 稳定性
- 任意单站异常（CF / WAF / 超时 / 验证码取消）不回导致 App 崩溃
- 网络异常有提示

### NFR-4 可维护性
- 适配器模式：新增站点 = 1 个类 + 2 处注册
- 域名外置配置，不改代码可换域名
- 完整对接文档（docs/）

### NFR-5 安全与合规
- 仅拉取公开索引数据，不存储资源文件
- 遵守当地法律法规，用户自行确认资源版权

## 5. 用户故事

1. 作为用户，我想输入"重器"一次搜到多个站的资源，以便挑一个网盘最快的下载。
2. 作为用户，我想按"狐狸君/6v520"等站看结果，以便我只习惯用某个站。
3. 作为用户，站点换域名后，我想在设置里改一下就能继续用。
4. 作为用户，雪落搜出验证码时，我想看清楚算式图手动填，而不是被卡死。
5. 作为用户，我被 Clash 代理环境困住时，想在设置里开代理让搜索能出结果。

## 6. 验收标准

- [x] batman 聚合 ≥ 10 站以上、≥ 100 条
- [x] 每个可用站点详情页能给出可复制资源链接
- [x] 域名 / 启停配置在设置页可改，改后立即生效
- [x] 验证码弹窗可刷新 / 取消 / 提交，图清晰可读
- [x] 单站故障不影响整体搜索

## 7. 风险与已知限制

| 风险 | 说明 | 对策 |
|---|---|---|
| Cloudflare 拦截站（SeedHub） | OkHttp 无法过纯 JS 挑战 | 适配器检测后返回空；用户可在设置停用 |
| 站点改版 / 换域名 | 解析器可能失效 | 域名可配 + 适配器独立，坏了单独修一处 |
| 验证码策略变化 | 雪落可能加复杂验证 | 手动弹图方案已就位，仅需升级 |
| 付费墙（panku8） | 链接需 VIP | 不接入，文档记录 |
| 短剧站英文词无结果 | 短剧狗只收中文 | 行为正常，不打补丁 |
